  - type String
  - metadata Json?

- Add InvestorEngagementStatus:

  - lastActiveAt DateTime?
  - score Int @default(0)

  - updatedAt

Backend:
- Create server/services/investorEngagement.ts:
  - recordActivity(userId, propertyId?, type, metadata?)
  - recomputeEngagement(userId) using simple scoring:

    - last 30 days = +5
    - older = +0
- Hook recording into existing investor flows:
  - marketplace property view
  - purchase flow
  - report view (if exists)

Add admin endpoint:
- GET /api/admin/engagement/summary

  - list top “at risk” users (lastActiveAt > 14 days)

- identify at-risk users and create Notification records if your app has notifications
- if no Notification model exists, add a minimal one (id, userId, message, status, createdAt)
