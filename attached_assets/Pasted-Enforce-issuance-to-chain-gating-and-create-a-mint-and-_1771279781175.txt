Add provider-agnostic KYC/accreditation scaffolding that updates InvestorProfile and can gate issuance track presets.

Backend:
- Create server/routes/compliance.ts mounted at /api/compliance
Endpoints:
1) POST /api/compliance/kyc/start (user)
  - sets InvestorProfile.kycStatus = PENDING
  - returns { redirectUrl or instructions } (stub)

2) POST /api/compliance/kyc/webhook (provider callback)
  - protect with COMPLIANCE_WEBHOOK_SECRET if set
  - updates InvestorProfile.kycStatus to APPROVED/REJECTED

3) POST /api/compliance/accreditation/start (user)
  - sets accreditationStatus=PENDING
  - returns stub instructions

4) POST /api/compliance/accreditation/webhook
  - updates accreditationStatus

UI:
- In investor settings page, add a “Verification” section:
  - show KYC status, accreditation status
  - buttons to start each flow (stub okay)
- Demo mode: statuses can be toggled for demo users.

Gating:
